# ADR 0007: Финальное имя — shelf-spec

## Статус

accepted — решение владельца, 2026-07-26. Закрывает нейминг-гейт (issue #3,
ARCHITECTURE § 10 п. 1).

## Контекст

Рабочее имя openshelf держалось до гейта перед продакшн-репо и публикацией
пакета. Проверка на дату решения:

- GitHub: имя `openshelf` носит 151 чужой репозиторий; доминирующее
  значение — книжные/библиотечные приложения, среди них живые проекты со
  звёздами. Поиск по имени уводит к ним, и это не изменится.
- Репозитория с именем `shelf-spec` на GitHub **нет вообще** (все
  совпадения поиска случайные); PyPI свободен по всем кандидатам
  (`openshelf`, `openshelf-spec`, `openshelf-mcp`, `shelf-spec`,
  `shelfspec` — перепроверено 2026-07-26).
- README уже называл продукт «shelf-spec — a portable, vendor-neutral
  memory format»: имя формата существовало отдельно от имени репо.
- «shelf» — морфема семейства (docshelf-mcp, memshelf-mcp, `*-shelf`
  полки): имя встраивается в существующий бренд, а не заводит новый.

## Решение

Единое имя **shelf-spec** для всего: репозиторий, PyPI-пакет, console
script `shelf-spec`, Python-модуль `shelf_spec`, env-переменная
`SHELF_SPEC_ROOT`, `$id` схемы, ссылки. Продукт — формат (ADR 0001), и имя
совпадает с продуктом.

## Альтернативы

- **openshelf как есть**: «open» честно сигналит vendor-нейтральность, но
  151 коллизия хоронит находимость навсегда. Отклонено.
- **openshelf-spec**: снимает коллизию, но плодит два имени (формат
  shelf-spec + пакет openshelf-spec), длиннее, и суффикс -spec слегка врёт
  — пакет несёт ещё валидатор и MCP-сервер. Отклонено.

## Последствия

- Переименование проведено до первой публикации — под старым именем не
  выходило ничего, миграционных прослоек не требуется (pre-1.0 политика).
- Владелец переименовывает GitHub-репо `openshelf` → `shelf-spec`
  (Settings → Rename; редиректы старых URL GitHub держит сам).
- Секрет для advisory-CI полок в `docs/advisory-ci.md` теперь называется
  `SHELF_SPEC_TOKEN`; если под старым именем `OPENSHELF_TOKEN` секрет уже
  был заведён — завести/переименовать при подключении advisory-стадий
  (issue #4).
- Дизайн-пакет 07 в arch-designs-shelf сохраняет историческое имя каталога;
  заголовки документов помечены «(ранее openshelf)».
